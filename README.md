## 🚀 Wie arbeitest du mit den Uebungen?

1. **Datei oeffnen**: Oeffne die Datei in Antigravity oder VS Code.
2. **Theorie & Musterbeispiele**: Lies dir den oberen Teil durch. Fuehre die Datei im Terminal aus, um die Musterbeispiele in Aktion zu sehen:
   `ash
   python 01_grundlagen_variablen.py
   `
3. **Aufgaben loesen**: Scrolle nach unten zu [DEINE UEBUNGSAUFGABEN]. Lies die Aufgabenstellung und trage deinen Code bei # Hier deinen Code schreiben: ein.
4. **Testen**: Fuehre die Datei im Terminal erneut aus und pruefe deine Ausgaben.
